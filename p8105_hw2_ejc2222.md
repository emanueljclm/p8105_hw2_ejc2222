This dataset contains information on each entrance and exit for each
subway station in New York City. The variables retained are line,
station name, station latitude/longitude, routes served (`route1`
through `route11`), entry, vending, entrance type, and ADA compliance. I
read in the data with `read_csv()`, cleaned the variable names with
`janitor::clean_names()`, kept the specified variables with `select()`,
and used `mutate()` to convert `entry` from “YES”/“NO” to a logical
variable (`TRUE`/`FALSE`). The resulting dataset has 1868 rows and 19
columns. The NAs in the route columns reflect stations that serve fewer
than 11 routes, not missing data.

### Reformatting route number and route name

To make route number and route name distinct variables, I converted
`route8` through `route11` to character so all route columns share the
same type, then used `pivot_longer()` to collapse the 11 route columns
into `route_number` and `route_name`, dropping empty route slots.

``` r
transit_long_df = 
  transit_df |> 
  mutate(across(route8:route11, as.character)) |> 
  pivot_longer(
    route1:route11,
    names_to = "route_number",
    values_to = "route_name",
    names_prefix = "route",
    values_drop_na = TRUE
  )
```
